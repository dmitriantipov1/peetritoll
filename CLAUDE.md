# Peetri Toll — сайт ресторана и музея (эскиз)

Сайт таверны-музея «Петровская Таможня» (Tavern Peetri Toll), Палдиски, Эстония.
Сейчас это вёрстка-прототип для согласования дизайна с заказчицей, а не боевой сайт.
Опубликован на GitHub Pages.

**Требования, статусы и открытые вопросы — в `REQUIREMENTS.md`.** Это единственный
источник правды по тому, что мы делаем. Новая договорённость с заказчицей сначала
записывается туда, потом кодируется.

`SCOPE.md` — версия для заказчицы: что входит в разработку, чего не будет,
что уже нарисовано.

`NOTES.md` — черновик для нового, пока оно не продумано: разбор созвона,
из которого решённое уезжает в требования. Сейчас закрыт, всё перенесено.

Этот репозиторий — **этап 0** (прототип дизайна) проекта, который дальше вырастает
в сайт с админкой, магазином и приёмом оплат. Приложение будет жить в отдельном
репозитории (см. 5.6 в требованиях), прототип остаётся здесь. Здесь, в этапе 0,
жёсткие правила ниже действуют без исключений; на будущие этапы они не распространяются.

## Жёсткие правила

- Только чистые HTML, CSS и JS. Без фреймворков, библиотек и сборщиков.
- Все пути относительные (`./css/...`, `./images/...`), иначе сломается подпапка GitHub Pages.
- Адаптив обязателен. Проверять на 1440, 1024, 860, 640 и 390 px.
- На планшете и телефоне (до 860 px) контентные фото показываются целиком, без обрезки (aspect-ratio: auto). Исключение — сетки-превью: галерея, товары, карточки блюд.
- В `<head>` всех страниц стоит `noindex`. Убрать только перед запуском.
- Формы, корзина, бронирование и переключатель языков пока не работают. Это визуальные заглушки.

## Структура

```
index.html      лендинг
restaurant.html Ресторан: залы и события, меню, бронь стола (карточка-форма, #bron — сюда ведут
                все «Забронировать стол»), галерея, отзывы. Первый пункт верхнего меню
about.html      О нас: семья, история здания и Палдиски, новости, партнёры
news.html       Новости: список с фильтром по темам, подписка. news-item.html — шаблон новости
event.html      Страница мероприятия (шаблон): описание, афиша, запись карточкой-формой.
                Сюда ведут «Записаться» на главной и в «Музее»
privacy.html    Политика конфиденциальности (черновик), cookies.html — о cookies,
404.html        страница «не найдено» (GitHub Pages отдаёт её сам). Ссылки на них — в футере
menu.html       Меню ресторана, карточки блюд по варианту 3 (строка с миниатюрой). Над ним —
                строка с кнопкой на «Меню дня». У блюда может быть
                несколько порций со своей ценой (.dish__sizes). Клик по фото открывает его
                крупно (<dialog class="lightbox">). Все пять вариантов
                остаются на elements.html (#dish-v1…#dish-v5)
museum.html     Музей (выставка, экспонаты, визит, мероприятия, архивы, книги, авторы)
lunch.html      Меню дня с предзаказом: вкладки Пн–Пт (открывается сегодняшний день), цены на суп,
                горячее и обед целиком, карточка «Ваш предзаказ» сбоку — считается только открытый день.
                Скрывается из админки вместе с кнопкой в «Меню»
author.html     Страница автора — шаблон-заглушка, одна на всех авторов (ссылки из «Музея»)
services.html   Экскурсии и поездки (с формой заявки, радиогиды)
banquet.html    Банкетный зал: о зале, запрос в три шага с калькулятором банкета.
                Вход — блок «Банкетный зал» в «Услугах», кнопки на главной и в «Ресторане».
                Отправки нет, показываем ответ гостю
group.html      Групповое меню: обед для экскурсионной группы, калькулятор без сетов.
                Вход — кнопка в герое главной и на странице «Ресторан». Отправки нет
contacts.html   Контакты: адрес, часы, как добраться, форма. Пункт меню «Контакты» ведёт сюда
shop.html       Магазин (фильтр по категориям; ссылка сразу на категорию — shop.html#books).
                Карточка товара .product: высота фиксирована, название и описание — по 2 строки
elements.html   Варианты блоков для согласования (мероприятия, бронь стола,
                дневное меню, калькулятор банкета, радиогиды, карточки блюд). В навигацию сайта
                не входит, ссылку заказчице отправляем напрямую.
                Калькулятор считает по-настоящему — отправки нет, расчёт есть.
css/style.css   все стили; токены (цвета, шрифты, сетка) в :root в начале файла
js/main.js      бургер-меню, переключатель языков (визуальный), вкладки, фильтры, фото блюд и галереи крупно,
                мероприятия по очереди с афишей (data-rotate, data-interval в секундах),
                варианты блоков на elements.html, заглушки картинок
images/         картинки (см. README.md)
admin/          админка, отдельный модуль: свои страницы и admin.css поверх css/style.css.
                Desktop first — правило про адаптив и проверку на 860–390 px на неё
                не распространяется. План по итерациям — 9.1 в требованиях
design/         к сайту не относится: tokens.json (токены из style.css для Tokens Studio в Figma)
                и boards/ — доски основы дизайна отдельными страницами, для импорта в Figma
```

Шапка и футер продублированы во всех HTML-файлах сайта (19, включая elements.html). Меняешь в одном — меняй во всех.

**Правило про кэш.** Ссылки на стили и скрипт содержат версию:
`./css/style.css?v=20261027`, `./js/main.js?v=20261027`. После правки `style.css`
или `main.js` версию надо поднять во всех HTML-файлах сайта и в страницах `admin/` — иначе у того, кто уже
открывал сайт, останется старая версия из кэша браузера, и правка «не появится».
Значение — дата правки, формат ГГГГММДД. Если правишь второй раз за день,
добавляй суффикс: `20261027-2`, иначе кэш не сбросится.

## Дизайн

- Шрифты (Google Fonts): Kurale — меню, кнопки, герой; Lora — заголовки и цитаты; Source Sans 3 — текст.
- Цвета: золото #CBAA58, тёмное золото #A66E0E, золото для текста #8A5B0B, красный #993122, коричневый #3C1F0C; фоны #EDE5D8 / #F4EFE6 / #E4DAC9.
- Контейнер 1280 px, поля clamp(20px, 4vw, 48px).
- Заголовок раздела (`.section-head`): надзаголовок, номер золотом + название, ссылка справа, линия снизу.
- Разделы чередуют фоны section--bg1 / bg2 / bg4.
- Если картинки нет, JS показывает полосатую заглушку с именем файла (атрибут `data-ph`).
- У каждой картинки золотая рамка внутри с отступом 12 px — правило в `style.css` на `.photo__frame`
  и других обёртках картинок. Исключение — товары (`.product`, обложки книг `.card__img`).
